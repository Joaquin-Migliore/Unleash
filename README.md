# UNLEASH 2026 keynote (web version)

Two files that must stay together in the same repository:
- index.html  (the keynote)
- joaquin.jpg (the headshot used on the About slide)

## Publish it free with GitHub Pages
1. Create a free account at github.com
2. New repository, name it "unleash" (Public)
3. Upload BOTH files (index.html + joaquin.jpg) to the repo
4. Settings > Pages > Source: "Deploy from a branch" > branch "main" > /(root) > Save
5. Wait ~1 minute. Your public link appears at the top of the Pages settings:
   https://YOUR-USERNAME.github.io/unleash/

Navigate the live page with the left/right arrow keys, or click the right/left half of the screen.
